# The Hungry Squirrel — website

Live site: **https://taykuy.github.io/taykuy.git.io/**

This repo hosts the published **Hungry Squirrel** pages — a rolling
Charlottesville household meal plan and a guest-facing supper-club menu — served
by GitHub Pages from the `main` branch.

## Pages

- **`hungrysquirrel.html`** — the meal plan: dinner rotation (ordered by
  perishability), market-first shopping list, and dish deep-dives.
  → https://taykuy.github.io/taykuy.git.io/hungrysquirrel.html
- **`HungryMenu.html`** — the guest-facing menu with RSVP and pairing suggestions.
  → https://taykuy.github.io/taykuy.git.io/HungryMenu.html
- **`index.html`** — landing page.

The pages are generated and maintained by the **Hungry Squirrel** meal-plan
skill and are self-contained HTML (inline CSS/JS).

## Updating the site

See **[PUBLISH.md](PUBLISH.md)** for the full runbook. Short version: the Cowork
cloud sandbox has no push credentials, so publish by uploading the updated files
(using these exact filenames) at
`https://github.com/taykuy/taykuy.git.io/upload/main` and committing to `main`.
